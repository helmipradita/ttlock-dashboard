## Reporting a Vulnerability

The TTLOCK Dashboard team takes the security of our IoT telemetry platform and user credentials seriously. If you discover a security vulnerability, **please do not create a public issue on GitHub**.

Instead, please responsibly report the vulnerability via private email:

- **Contact**: Helmi Pradita
- **Email**: `helmipraditaa@gmail.com`
- **Subject Line**: `[SECURITY VULNERABILITY] TTLOCK Dashboard`

### What to Include in Your Report:
1. Detailed description of the vulnerability and its potential impact.
2. Step-by-step reproduction steps or a minimal proof of concept (PoC).
3. Affected components (backend API, web frontend, Docker configuration, or authentication lifecycle).
4. Suggested remediation or patch, if available.

### Our Response Timeline:
- **Initial Response**: Within 48 hours of report receipt.
- **Triage & Assessment**: Within 5 business days.
- **Fix & Public Advisory**: Coordinated disclosure within 30 days after a validated patch is deployed.

Thank you for helping keep TTLOCK Dashboard secure for the open-source community!
